# Segurança e governança

- Nunca inserir segredos no código ou neste repositório.
- Configurar por ambiente.
- Aplicar princípio do menor privilégio.
- Mascarar dados pessoais e sensíveis quando aplicável.
- Usar `correlation_id`, logs estruturados e rastreabilidade quando aplicável.
- Para operações críticas, preservar aprovação humana quando exigida.
- Não transformar dados privados em conteúdo público apenas para facilitar automação.
