# Engenharia de software

- Entregar código pronto para uso real.
- Incluir validações e tratamento de erros.
- Usar logs estruturados.
- Configurar por ambiente.
- Não usar hardcode de segredos.
- Incluir testes automatizados.
- Fornecer exemplos de execução.
- Manter documentação e changelog quando aplicável.
- Preferir idempotência e operações seguras para reprocessamento.
- Em fluxos assíncronos, considerar fila, backpressure, retentativas controladas, quarentena/DLQ e concorrência segura.
